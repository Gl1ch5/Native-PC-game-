# Native PC Game

Android-приложения, которые запускают ПК-игры как обычные мобильные игры: иконка на рабочем столе, загрузка и распаковка с прогрессом, выбор управления и сразу заставка игры, без окон Windows и меню эмулятора.

В основе — [Winlator Cmod](https://github.com/coffincolors/winlator) (MIT): Wine + FEXCore/Box64 + DXVK + Turnip/системный Vulkan. Репозиторий хранит только своё: патч к апстриму, код лаунчера и описания игр. Код Winlator подтягивается при сборке.

## Скачать

Готовые APK лежат в релизе **[Nightly](../../releases/tag/nightly)**, он обновляется после каждого изменения в основной ветке.

У каждой игры своё имя пакета (F1 2012: `com.gl1ch5.f12012`), поэтому игры ставятся рядом друг с другом и рядом с Winlator Cmod.

## Что видит игрок

1. **Первый запуск.** Экран выбора: управление (геймпад, сенсорное, гироскоп, клавиатура) и качество: «Экономия» 720p/45 FPS, «Баланс» 720p/60 FPS, «Качество» 1080p/60 FPS. Потом это меняется кнопкой «Настройки».
2. **Установка.** Подготовка движка, загрузка (с докачкой) и распаковка RAR/7z/zip/tar.zst. Прогресс виден на экране и в уведомлении, там же кнопка «Отмена». Загрузка продолжается, если свернуть приложение.
3. **Запуск.** При следующих открытиях игра стартует сама через 1,5 секунды, сразу в `.exe`, без рабочего стола Wine.
4. **В игре** кнопка «Назад» ставит игру на паузу и открывает меню: смена управления на лету, чувствительность и калибровка руля-гироскопа, выход.

Скрытый вход в полный интерфейс Winlator для отладки: долгое нажатие на название игры на экране запуска.

### Против нагрева

Лимит кадров через `DXVK_FRAME_RATE` (45 или 60), рендер в 720p с растяжением на экран, DXVK gplasync (асинхронная компиляция шейдеров), HUD и логи Wine отключены. Ядра процессора по умолчанию не ограничиваются: главный поток игры после трансляции x86→ARM нуждается в самом быстром ядре. Если нужно, привязка задаётся полем `cpuList`.

### Управление

| Режим | Как работает |
|---|---|
| Геймпад | Физический контроллер (Bluetooth/USB) как XInput. Экранных кнопок нет. |
| Сенсорное | Экранный стик (руль), педали «ГАЗ»/«ТОРМОЗ», ABXY, LB/RB, START/BACK, крестовина для меню. |
| Гироскоп | Руль — наклон телефона (абсолютный угол по вектору гравитации, не скорость вращения). Педали и кнопки на экране. Чувствительность и «Центр» — в меню паузы. |
| Клавиатура | Bluetooth-клавиатура и мышь, без экранных кнопок. |

### Драйвер видеокарты

По умолчанию используется системный драйвер Qualcomm. В «Настройках» можно выбрать свой: кнопка «Из архива…» принимает ZIP-архив драйвера Adrenotools (внутри `meta.json` и `.so`), например сборку Turnip. Если выбранный драйвер удалён, приложение вернётся к системному.

Раскладки лежат в `games/<id>/controls_touch.icp` и `controls_tilt.icp` (формат профилей Winlator).

## Как добавить или настроить игру

Пошаговая инструкция для нового порта — **[docs/NEW_GAME.md](docs/NEW_GAME.md)**. Коротко:

```bash
python3 tools/new_game.py nfs-mw --title "Need for Speed: Most Wanted" --package com.gl1ch5.nfsmw \
  --exe speed.exe --preset racing --url https://cloud.mail.ru/public/XXXX/YYYY/nfsmw.rar
python3 tools/validate_games.py
```

Каждая папка в `games/` (кроме `_template`) после пуша становится отдельным APK в релизе Nightly.

```
games/<id>/
  gamepack.json        название, ссылки на архив, exe, настройки контейнера
  controls_touch.icp   сенсорная раскладка
  controls_tilt.icp    раскладка для режима «гироскоп» (без стика)
  NOTICE.md            условия правообладателя
  branding/            необязательно: background.jpg (фон, 16:9), icon.png (512×512)
```

Без `branding/` используются нейтральный фон и своя иконка (клетчатый флаг).

Главное в `gamepack.json`:

- `packageId`: имя пакета Android, у каждой игры своё. **Не длиннее 17 символов**: путь `/data/data/com.winlator.cmod` зашит в бинарники системного образа, и `android/rebrand.py` заменяет его строкой той же длины.
- `download.parts`: ссылки на архив. Поддерживаются **публичные ссылки Облака Mail.ru** (`https://cloud.mail.ru/public/...`), **Яндекс.Диска** (`https://disk.yandex.ru/d/...` или `https://yadi.sk/...`, через «Поделиться → Скопировать ссылку») и прямые HTTP-ссылки. Многотомный архив (`.part1.rar`, `.part2.rar`, …) — несколько записей по порядку. `sha256` можно оставить пустым.
- `install.dir` / `install.exe`: куда распаковать внутри `C:\` и какой exe запускать. Exe ищется по имени в любой подпапке архива.
- `container`: версия Wine, DXVK, лимит кадров по умолчанию, переменные окружения.


## Сборка

CI (`.github/workflows/build-apk.yml`) делает всё сам. Локально (нужны JDK 17, Android SDK, NDK 27.0.12077973, CMake 3.22.1, `gh`):

```bash
android/prepare.sh f1-2012 build/f1-2012          # апстрим + патч + лаунчер + игра
android/fetch-system-assets.sh build/f1-2012      # imagefs.txz и proton-*.txz из релиза Cmod
python3 android/rebrand.py build/f1-2012 com.gl1ch5.f12012   # своё имя пакета (нужен pip-пакет zstandard)
cd build/f1-2012 && ./gradlew assembleDebug
```

### Подпись Nightly

Чтобы новые сборки ставились поверх старых, нужен постоянный ключ. Создайте его один раз:

```bash
keytool -genkeypair -v -keystore debug.keystore -alias androiddebugkey \
  -storepass android -keypass android -keyalg RSA -keysize 2048 -validity 10000 \
  -dname "CN=Android Debug,O=Android,C=US"
base64 -w0 debug.keystore
```

Вывод сохраните в секрет репозитория `ANDROID_DEBUG_KEYSTORE_B64` (Settings → Secrets and variables → Actions).

## Права

Файлы игр в репозитории не хранятся: лаунчер скачивает их по ссылке из `gamepack.json`. Использование F1 2012 согласовано с правообладателем, только в некоммерческих целях. Условия и пометки правообладателя — в [`games/f1-2012/NOTICE.md`](games/f1-2012/NOTICE.md). Winlator Cmod распространяется под MIT, компоненты Wine/Box64/FEX/Mesa/DXVK — под своими лицензиями.
