# Как сделать порт новой игры

Каждая игра — это папка `games/<id>/`. После пуша CI сам собирает из неё отдельный APK со своим именем пакета, иконкой и названием и выкладывает его в релиз **Nightly** рядом с остальными. Java-код и патчи трогать не нужно.

## 1. Что подготовить

- **Разрешение правообладателя** на использование файлов игры. Его текст пойдёт в `NOTICE.md`.
- **Архив с установленной игрой**: RAR (включая RAR5 и многотомные), 7z, zip или tar.zst. Внутри должна быть папка игры с exe, без установщика. Игра должна запускаться из этой папки без регистрации в реестре. Если ей нужны записи реестра, это решается отдельно (см. «Если игра не запускается»).
- **Публичная ссылка** на архив: Облако Mail.ru (`cloud.mail.ru/public/...`), Яндекс.Диск (`disk.yandex.ru/d/...`) или прямая HTTP-ссылка.
- **Имя exe**, например `speed.exe`. Его ищут по имени в любой подпапке архива.
- **Имя пакета** — уникальное, не длиннее 17 символов: `com.gl1ch5.nfsmw`, `com.gl1ch5.gta_vc`.

## 2. Создать папку

```bash
python3 tools/new_game.py nfs-mw \
  --title "Need for Speed: Most Wanted" \
  --package com.gl1ch5.nfsmw \
  --exe speed.exe \
  --preset racing \
  --url https://cloud.mail.ru/public/XXXX/YYYY/nfsmw.rar
```

На Windows: `py tools\new_game.py ...` (те же параметры).

Скрипт копирует `games/_template`, подставляет значения, кладёт раскладки управления и сразу запускает проверку.

| `--preset` | Для каких игр | Режимы управления |
|---|---|---|
| `racing` | гонки | сенсорный руль и педали, гироскоп, геймпад, клавиатура |
| `gamepad` | экшен, платформеры, спорт | экранный геймпад, гироскоп, геймпад, клавиатура |
| `keyboard` | стратегии, игры под мышь | клавиатура и мышь, геймпад |

## 3. Донастроить `gamepack.json`

| Поле | Зачем |
|---|---|
| `title` | Название под иконкой и на экране запуска. |
| `notice` | Строка мелким шрифтом в углу экрана запуска. |
| `packageVersion` | Увеличьте, если поменяли архив: у игроков он скачается заново. |
| `download.parts` | Части архива по порядку. `sha256` необязателен, но защищает от битых загрузок. |
| `download.archivePassword` | Пароль архива, если есть. |
| `install.dir` | Куда распаковать внутри `C:\`. |
| `install.exe`, `install.execArgs` | Что запускать и с какими аргументами (например `-windowed`). |
| `install.minFreeSpaceMb` | Сколько места проверить перед загрузкой: архив плюс распакованная игра. |
| `controls.modes`, `controls.default` | Какие режимы показывать и какой выбран при первом запуске: `TOUCH`, `TILT`, `GAMEPAD`, `KEYBOARD`. |
| `container.frameRateLimit` | Лимит FPS по умолчанию (игрок меняет его пресетом качества). |
| `container.dxvkVersion` | `2.4-gplasync` для DirectX 9–11. Для старых DX8-игр попробуйте `1.10.3`. |
| `container.envVars` | Переменные окружения Wine/DXVK/Mesa. |
| `container.cpuList` | Привязка к ядрам, например `"2,3,4,5,6,7"`. Пусто — все ядра. |
| `container.box64Preset` | `PERFORMANCE` или `STABILITY`, если игра падает. |

## 4. Раскладка управления (если нужно)

`controls_touch.icp` и `controls_tilt.icp` — профили Winlator в JSON. Координаты `x`/`y` от 0 до 1 (доля экрана), `scale` — размер, `bindings` — кнопки геймпада или клавиши (`GAMEPAD_BUTTON_A`, `KEY_W`, `MOUSE_LEFT_BUTTON`…), `text` — подпись. Первые три ключа — `id`, `name`, `cursorSpeed`, именно в таком порядке. Удобно разложить кнопки в Winlator на телефоне (долгое нажатие на название игры → полный интерфейс → Input Controls), экспортировать профиль и положить его сюда.

В раскладке для гироскопа не должно быть левого стика: руль подаётся наклоном.

## 5. Оформление (необязательно)

`branding/background.jpg` (1920×1080) и `branding/icon.png` (512×512). Только то, на что есть права.

## 6. Проверить и отправить

```bash
python3 tools/validate_games.py
git add games/nfs-mw && git commit -m "Add Need for Speed: Most Wanted" && git push
```

CI проверит все игры, соберёт APK и обновит Nightly. Игру с ошибкой в `gamepack.json` проверка не пропустит, и сборка не начнётся.

## Если игра не запускается

- **Чёрный экран или вылет на старте:** попробуйте `"box64Preset": "STABILITY"`, другую `dxvkVersion` или `"envVars"` с `MESA_EXTENSION_MAX_YEAR=2003` для старых игр.
- **Нужны записи реестра или DirectX/VC++ runtime:** соберите архив так, чтобы игра была переносной (portable). Как вариант — положите рядом с exe `.bat`, который сначала импортирует `.reg`, и укажите его в `install.exe`.
- **Лаунчер или DRM вместо игры:** укажите в `install.exe` сам исполняемый файл игры, а не лаунчер.
- **Посмотреть, что происходит:** долгое нажатие на название игры открывает полный интерфейс Winlator. Там можно включить логи и подобрать настройки, а потом перенести их в `gamepack.json`.
