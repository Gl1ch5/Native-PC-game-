# Оформление (необязательно)

| Файл | Что это | Размер |
|---|---|---|
| `background.jpg` (или `.png`, `.webp`) | Фон экрана запуска | 1920×1080, тёмная левая часть: там текст и кнопки |
| `icon.png` | Иконка на рабочем столе | 512×512, квадрат |

Без этих файлов используются нейтральный фон и иконка с клетчатым флагом.

Кладите сюда только то, на что у вас есть права: официальные логотипы и обложки обычно принадлежат издателю или владельцу товарного знака.
